## UI Fixes This Round

- Network Diagnostics server select uses a fixed normal-width field:
  `420px`, `min-width: 320px`, `max-width: 420px`.
- Network Diagnostics interface select uses a fixed normal-width field:
  `280px`, `min-width: 220px`, `max-width: 280px`.
- Select controls use `padding: 0 38px 0 10px`, `appearance: none`, and a CSS
  arrow so the arrow cannot cover short text.
- Target input is shortened to a flex field with normal basis `360px` and max
  `380px`; TCP mode uses a smaller target field and keeps the port input.
- Diagnostic state is now an aligned badge:
  - `is-idle`: `暂无任务`
  - `is-running`: `运行中`
  - `is-completed`: `已完成`
  - `is-canceled`: `已取消`
  - `is-failed`: `失败`
- Bottom status bar now renders transfer status first and tunnel status after
  it, so `隧道 0` appears to the right of `无传输`.
